01

解决什么具体问题

影石面向 200 多个国家开展达人营销，但一次合作从选人到复盘，很多判断仍靠经办人经验完成：

选人

候选池巨大，靠经验覆盖有限

人工容易集中在已走红的账号；粉丝量相近的达人，实际场景表达和转化能力差异很大。

推荐理由

缺少证据，难以复核

BD 难以复核推荐依据，也难向团队解释预算选择。

内容

脚本与文案逐条手工打磨

合作脚本和本地化文案跟不上全球新品推广节奏。

复盘

经验无法复用

哪类达人、哪种内容带来了转化，缺少统一记录和可靠归因——每轮选人都接近重新开始。

02

竞品分析：为什么现有平台不够

调研了 5 家主流达人营销平台的能力矩阵（HypeAuditor / Modash / CreatorIQ / Traackr / GRIN）：

主流平台已覆盖粉丝量之外的内容匹配、AI shortlist、计划与衡量。 「AI 选人」「闭环」「生成 Brief」这些功能名称不足以构成差异——真正没人做、必须自建的是下面四个点。
差异点 1

产品场景 → 可计算任务

把产品使用场景定义成可计算的任务，而非通用标签。

差异点 2

证据绑定到每个判断

将公开视频时间片和评论语义证据绑定到每个推荐判断。

差异点 3

以「组合」为决策对象

以角色互补的达人组合（而非单个达人）作为投放决策对象。

差异点 4

私有数据校准

用自有历史合作结果按时间切点校准——私有数据护城河。

另有平台 API 可得性分析（YouTube / TikTok / Instagram / FTC 披露规则）与 8 篇学术文献映射支撑方法选型。
03

工具设计原理：三层决策漏斗

逐级收窄：先硬筛合规候选，再做场景化评分，最后以组合优化输出投放方案。

第一层 · 资格层

市场 / 语言 / 合规硬筛 → 合格候选池

↓

第二层 · 匹配层

场景内容评估 → 角色判断 + 任务适配分 + 证据卡

↓

第三层 · 组合层

预算 / 角色互补 / 集中度约束 → 稳健型 & 进取型投放组合

Score = w₁·市场 + w₂·场景 + w₃·内容能力 + w₄·受众 + w₅·角色信号 + w₆·势能 − w₇·风险 − w₈·成本
六维场景匹配

权重按任务类型配置

场景持续性 / 产品承载能力 / 内容复刻性 / 需求强度 / 增长势能 / 合作与风险。

四角色组合

不用一套指标评价所有人

引爆 / 扩散 / 转化 / 潜力探索——像投资组合一样配置达人。

组合优化

OR-Tools CP-SAT 求解

目标函数含场景覆盖、角色覆盖、探索价值；约束含预算上限、单人预算占比 ≤35%。

证据卡机制

每个推荐都可追溯

每个推荐附视频时间片 + 评论语义证据，可追溯率目标 100%。

验证设计

历史回放协议

  • 以合作开始日为时间切点，隐藏切点后数据，只用当时可得信息重跑选人引擎，与真实业务结果比较
  • 4 组对照基线（粉丝量 / 互动率 / 受众匹配 / 人工 shortlist）+ 3 组消融实验
  • 指标：NDCG@10、Precision@10、Spearman ρ、Macro-F1，含 bootstrap 95% 置信区间
  • 时间泄漏率目标 0%，发现一处即该批回放无效
交付形态

Skill 化交付 + 完整技术方案

  • 系统以 AI Skill 形态交付（提示词工作流封装，业务方可直接使用）
  • 另完成完整技术方案设计：FastAPI + Temporal + PostgreSQL/pgvector + Whisper/PaddleOCR + VLM + 飞书 Aily 入口

端到端演示

北美骑行新品案例

诚实说明

效率数字为验证目标值

文档中的效率数字（候选整理时间 −30%、任务整理时长 −50%、NDCG 提升 ≥20%）为方案设定的验证目标值；历史回放协议已设计完毕，尚未用真实案例全量跑过。

下一步完善方向 挑 5–10 个历史合作案例（公开数据即可）按回放协议手动跑一遍小规模真实回放，把「目标值」变成「小样本实测值」——「真的验证过」和「只设计了验证」是完全不同的分量。
